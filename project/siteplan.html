EmpowerTech Girls Foundation

A website designed to connect girls ages 10–17 with technology learning opportunities, scholarships, support, mentors, and a community of people who want to help them grow.

View Wireframes Explore Site Plan

01

Site Name

EmpowerTech Girls Foundation

The name combines Empower, which represents giving girls confidence and opportunities, with Tech, which represents technology and digital skills. The name clearly communicates the foundation's focus.

Possible domain: empowertechgirls.org

02

Site Purpose

The purpose of the EmpowerTech Girls Foundation website is to provide information and practical support for girls ages 10–17 who are interested in technology. The website will explain available learning programs, provide scholarship and support opportunities, allow eligible learners to apply, and show the impact of the foundation.

The website will also make it easy for parents, donors, mentors, volunteers, schools, organizations, and technology companies to learn how they can support the foundation.

08

Design, Accessibility, and Usability

Proximity

Related headings, descriptions, buttons, and form information will be grouped together.

Alignment

Content will follow a consistent grid, spacing system, and alignment pattern.

Repetition

The same colors, fonts, buttons, navigation patterns, and spacing will be repeated across pages.

Contrast

Text and interface elements will use sufficient contrast to remain readable and distinguishable.

Accessibility

Semantic HTML, logical headings, meaningful alternative text, labels, keyboard-friendly controls, and readable text will be used.

Responsive Design

The layout will adapt to mobile portrait, mobile landscape, tablet, and larger screens.

09

Testing Plan

  • Validate HTML and CSS before submission.
  • Check accessibility, heading structure, labels, alternative text, and color contrast.
  • Test navigation and interactive elements at different screen sizes.
  • Check spelling, grammar, links, and page consistency.
  • Optimize images and use lazy loading where appropriate.
  • Check basic SEO elements such as title, description, headings, and meaningful links.
  • Test the required JavaScript functionality, form behavior, and local storage in the final project.
