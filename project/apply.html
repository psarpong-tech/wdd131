Who Is This For?

The initiative is intended for girls ages 10–17 who are curious about technology and interested in learning digital skills.

For learners under 18, a parent or legal guardian should help review any application and provide required consent.

Before You Apply

  • Discuss the learner's interests with a parent or guardian.
  • Review the learning topics and any published eligibility requirements.
  • Prepare accurate contact information for the parent or guardian when an official application is available.
  • Check for official announcements about available opportunities and deadlines.

Important: This website does not confirm that applications, scholarships, or program places are currently open.

Application Steps

  1. Explore: Read about the program areas.
  2. Check eligibility: Review age and opportunity requirements when announced.
  3. Get guardian support: A parent or guardian should help with the process.
  4. Use an official channel: Submit details only through a verified application link when one is available.
