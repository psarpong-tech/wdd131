Learn by exploring

Program Areas

These learning areas are intended to introduce girls to useful digital skills and help them explore their interests in technology.

Start with the basics

Digital Skills

Digital skills help learners use technology confidently, safely, and responsibly in school and everyday life.

Possible learning topics

  • Computer and device basics
  • Typing and digital documents
  • Internet research and online safety
  • Digital communication and collaboration

Create with code

Coding and Web Development

Beginner-friendly coding activities can help girls understand how digital products work and how their ideas can become projects.

Possible learning topics

  • Introduction to programming concepts
  • HTML and CSS for web pages
  • Basic problem-solving with code
  • Planning and building simple projects

Think and collaborate

Innovation and Problem-Solving

Technology is also about understanding people's needs, testing ideas, and working with others to solve problems.

Possible learning topics

  • Creative thinking and design
  • Teamwork and communication
  • Identifying everyday challenges
  • Developing and presenting ideas

Learning support

More Than Technology Skills

As the initiative develops, we hope to explore mentorship, access to learning resources, scholarship information, and connections to further educational opportunities. Availability and eligibility would depend on the opportunities offered.
